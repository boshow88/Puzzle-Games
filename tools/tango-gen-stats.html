Tango generator stats

Runs N puzzles per (size, difficulty) combination and reports average prefill count, wall count, tier-tagged erasures, and how many cells each tier leaves unsolved. Tier definitions (chain length measured by backward closure — only the L1 placements actually needed for the contradiction count): L1 = direct rules; L2 = single-line hypothesis, chain = 1; L3 = single-line hypothesis, chain ≥ 2; L4 = anywhere-on-board hypothesis, chain ≤ 5 (with a wall-chain discount: any maximal connected run of T-wall placements of size K inside the chain is counted as ceil(K/3), since consecutive walls are visually mechanical). Difficulty: Easy = L1+L2, Medium = +L3, Hard = +L4. For Hard only, we also walk the solve trace and report how many L4 deductions actually used the wall-chain discount (rawChainLength > chainLength): L4 disc avg = avg discounted L4 steps per puzzle, disc K = puzzles with ≥1 such step, max save = largest single-step savings. unverified shows how many puzzles in the sample ultimately ended up unverified (generator's erase-time checks passed but the final state can't actually be solved by the allowed tactics; `generate` already retries best-of-N to avoid returning these).
