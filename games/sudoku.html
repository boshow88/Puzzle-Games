How to play

  • Click a cell to select it. Pre-filled (locked) cells stay grey.
  • Fill a digit with the on-screen keypad or your keyboard. The same key again clears that digit.
  • Toggle ✎ Notes (or press N) to write small candidate marks instead of a full digit.
  • Each row, column and box must contain every digit exactly once.
  • Backspace / Delete / 0 clears the cell. Arrow keys move the selection.
