Puzzle Games

A collection of logic puzzles inspired by LinkedIn's daily games.

♛
Queens
Royal regions, one queen each.

Place N queens so that every row, column, color region and 8-neighborhood contains exactly one.

5×5 – 12×12 Playable
☀
Tango
Sun & moon balance.

Fill the grid with suns and moons — half of each per row and column, no three in a row, respect the walls.

6×6 · 8×8 · 10×10 Coming soon
🔢
Sudoku
Classic number logic.

Multi-size Sudoku (4×4 / 6×6 / 9×9) with notes and clean rules — every puzzle has a unique solution.

4×4 · 6×6 · 9×9 Coming soon

Zip
One path, every cell.

Draw a single Hamiltonian path through the grid, visiting numbered checkpoints in order.
